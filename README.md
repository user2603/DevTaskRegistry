# DevTaskRegistry

Central registry for the team's proposal tasks.

- Developers push proposal packages on their `dev/<name>` branches under `tasks/proposals/`.
- Every proposal's `docs/task.md` cites the template it was built on. Whether that citation holds up is defined by the template folders under `tasks/templates/` and the rules in `tasks/README.md` — check them, do not guess.
- The Notion `Task Ledger` database on the `Task Tracker` page mirrors the registry state between review cycles.
